# CellMap 荣耀版 1.0.9

适配荣耀 WIN / MagicOS（Android）。源码在 `main` 分支的 `cellmap/` 目录。

| 项目 | 值 |
| --- | --- |
| APK | `cellmap-honor-1.0.9.apk` |
| 包名 | `com.selfuse.cellmap.honor` |
| 版本 | 1.0.9 (versionCode 10) |
| 签名证书 SHA-1 | `62:68:5D:90:EE:E5:FD:91:2C:B4:BB:E1:7D:FF:53:92:F4:B6:6F:1F` |

## 安装

1. 下载 APK，点击安装，允许安装未知来源应用。
2. 首次启动授予通知权限，并在系统设置中允许后台运行、关闭电池优化。
3. 安装后与鸿蒙版可以同机共存，但两边数据独立，需要分别导入。

## 本版更新

- 地图搜索结果支持长按选词、复制。
- 窗口请求当前分辨率下的最高刷新率，适配 30/60/90/120/144/165/185Hz 面板；省电模式下不强制。
- 后台任务前台通知不可用时降级继续执行。

## 刷新率说明

Android 应用只能声明刷新率偏好，最终档位由屏幕面板与系统温控决定。若显示仍为 60Hz，请检查系统「智能刷新率 / 省电模式」是否开启，并在开发者选项打开刷新率显示确认。应用在省电模式下主动放弃高刷请求。

## 天地图 Key

若使用「Android 平台」Key，需在天地图控制台为 `com.selfuse.cellmap.honor` + 上述 SHA-1 单独绑定；浏览器端 Key 不受包名限制。两个版本共用同一份 Key 配额。
