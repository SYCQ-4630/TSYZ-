# CellMap 鸿蒙版 1.2.1

适配华为 Mate 60 Pro / HarmonyOS 6.1，通过卓易通兼容层安装运行。源码在 `main` 分支的 `cellmap/` 目录。

| 项目 | 值 |
| --- | --- |
| APK | `cellmap-huawei-1.2.1.apk` |
| 包名 | `com.selfuse.cellmap.huawei` |
| 版本 | 1.2.1 (versionCode 13) |
| 签名证书 SHA-1 | `62:68:5D:90:EE:E5:FD:91:2C:B4:BB:E1:7D:FF:53:92:F4:B6:6F:1F` |

## 安装

1. 下载 APK，点击安装，允许安装未知来源应用。
2. 首次启动授予通知权限，并在系统设置中允许后台运行、关闭电池优化。
3. 与荣耀版可以同机共存，但两边数据独立，需要分别导入。
4. 从 1.1.0 / 1.2.0 覆盖安装会执行数据库增量迁移，已导入数据与标注结果保留。

## 本版更新

- 基站详情面板信息区独立滚动，右侧显示滚动条，字段再多也能完整查看。
- 「关闭 / 居中到该点」固定在详情面板底部，不再被内容挤出屏幕。
- 导入支持带宽、上下行中心频点、部署方式、方位角、PCI、多载波、天线增益、AAU/RRU 数量等字段。
- 近似表头按字段类别分组提示，逐类确认后写入；天线挂高多种写法归入同一字段。
- 地图视野查询使用列投影，字段扩充后大结果集平移与缩放仍流畅。
- 搜索结果展开详情与底部详情面板均支持长按选词复制，并适配 30-185Hz 刷新率面板。

## 刷新率说明

Android 应用只能声明刷新率偏好，最终档位由屏幕面板与系统温控决定。若显示仍为 60Hz，请检查系统「智能刷新率 / 省电模式」是否开启，并在开发者选项打开刷新率显示确认。

## 天地图 Key

若使用「Android 平台」Key，需在天地图控制台为 `com.selfuse.cellmap.huawei` + 上述 SHA-1 单独绑定；浏览器端 Key 不受包名限制。两个版本共用同一份 Key 配额。
