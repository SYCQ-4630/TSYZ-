# 通信工单助手（TicketTool）

面向通信网络优化工程师的 Windows 桌面工具。把工单系统里复制出来的文本，按可维护的规则库自动拆成字段，持续追加到现有 Excel 表格，同时在本机保存结构化数据，支持精确查询、原文溯源、规则版本回退、快照恢复与日志诊断。

## 功能

- 模板绑定现有 `.xlsx`：读取表头生成字段，不改变原表样式，只向末尾追加数据行。
- 规则库：字段名称锚点、预置领域字段、分段取值、高级模式四种规则，支持优先级、启用开关、试跑与跨模板复制。
- 字段预览：逐项展示识别值、状态与提示；未识别项高亮，可直接在表格中手动补充后导入。
- 安全入库：工单、原文压缩包与溯源区间在同一个事务中写入；表格写入使用临时文件加原子替换，并保留 `.backup`。
- 后台同步：表格被 Excel 占用时数据先入库，关闭表格后自动补写；失败可重试。
- 精确查询：工单号、联系方式、投诉地址三类核心字段使用独立索引，命中后可直接查看原文高亮位置。
- 规则版本：每次保存自动生成版本，可一键回退。
- 快照恢复：每 30 秒保存未确认的编辑态；异常退出后启动时询问是否恢复。
- 诊断：结构化日志、同步队列、数据完整性检查、在线备份、一键导出诊断包。
- 导出：按模板导出 CSV / TSV。

## 运行环境

- Windows 10 1809 及以上，或 Windows 11。
- .NET 8 Desktop Runtime（若使用框架依赖发布）。
- 目标表格为 `.xlsx`，第一个工作表，首行为表头。

## 构建

```bash
# 还原与构建
dotnet build TicketTool.sln -c Release

# 运行测试
dotnet test tests/TicketTool.Tests/TicketTool.Tests.csproj

# 发布 Windows 版本（需要 Windows 或带 EnableWindowsTargeting 的环境）
dotnet publish src/TicketTool.App/TicketTool.App.csproj -c Release -r win-x64 --self-contained false
```

非 Windows 环境构建 WPF 时，项目已通过 `Directory.Build.props` 打开 `EnableWindowsTargeting`；产物只能在 Windows 上运行。

## 第一次使用

1. 启动程序，点击“创建示例”，会生成示例模板和示例工单文本，可直接体验完整流程。
2. 或点击“新建模板”，选择现有 Excel 文件，确认表头行号，点击“检测表头”，核对字段名称后保存。
3. 回到“工单录入”，粘贴工单文本。选择模板后会自动识别。
4. 核对预览结果，必要时修正字段值，点击“确认导入”。
5. 数据先写入本机数据库，随后自动追加到 Excel。顶部徽标显示同步状态。

## 规则说明

每个字段可以配置多条规则，按优先级从高到低执行，格式校验通过的结果优先采用。

| 类型 | 用途 |
| --- | --- |
| 字段名称锚点 | 匹配“工单号：”“联系电话：”等名称，取冒号后的内容 |
| 预置领域字段 | 内置工单号、电话、地址、星级、日期、IP、IMEI 等常见字段的名称与格式 |
| 分段取值 | 按分隔符切分后取指定段 |
| 高级模式 | 正则表达式，适合复杂格式；仅建议维护人员使用 |

“试跑当前字段”会用主界面当前原文立即展示每条规则的命中情况，不会修改数据。

## 数据与备份

默认数据目录：`%LOCALAPPDATA%\TicketTool\`

- `ticket.db`：SQLite 数据库（WAL 模式）
- `logs\`：按天滚动的结构化日志，保留 30 天
- `backups\`：每日自动备份与手动备份
- `temp\`：表格写入临时文件
- `diagnostics\`：诊断包输出目录

可通过环境变量 `TICKETTOOL_DATA_DIR` 指定其他数据目录，便于绿色部署或测试。

备份使用 SQLite 的 `VACUUM INTO`，不会直接复制正在写入的数据库文件。恢复时请先退出程序，再用备份文件替换 `ticket.db`。

## 快照与恢复

编辑中的原文和预览修正会定期保存为快照。正常退出时会写入一份“干净退出”快照并在下次启动时静默清理；异常退出后，启动时会显示保存时间、模板和阶段，由用户决定恢复或丢弃。快照最多保留 30 份。

## 诊断

“诊断与备份”页可以：

- 按级别、模块、关键词筛选日志。
- 查看未完成的同步任务并重试。
- 执行数据库完整性检查。
- 立即备份。
- 导出诊断包（包含日志、配置摘要、同步队列摘要，不包含数据库主文件）。

## 已知边界

- 只处理 `.xlsx`，不支持 `.xls`、`.csv` 作为目标表。
- 只写入第一个工作表，追加在现有最后一行之后。
- 不提供 XLSX 反向导入；批量导入请使用 CSV / TSV。
- 搜索为精确匹配，不做模糊检索。
- 单用户单机使用，不包含多人协作与云端同步。
