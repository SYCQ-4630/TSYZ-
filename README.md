# CellMap 鸿蒙版 1.0.9

适配华为 Mate 60 Pro / HarmonyOS 6.1，通过卓易通运行 Android 应用。源码在 `main` 分支的 `cellmap/` 目录。

| 项目 | 值 |
| --- | --- |
| APK | `cellmap-huawei-1.0.9.apk` |
| 包名 | `com.selfuse.cellmap.huawei` |
| 版本 | 1.0.9 (versionCode 10) |
| 签名证书 SHA-1 | `62:68:5D:90:EE:E5:FD:91:2C:B4:BB:E1:7D:FF:53:92:F4:B6:6F:1F` |

## 安装

1. 下载 APK 并传到手机，在卓易通内选择「本地安装」，允许安装未知来源应用。
2. 首次启动授予通知权限；容器内无法跳转电池优化设置时忽略，导入期间保持应用在前台。
3. 与荣耀版可以同机共存，但两边数据独立，需要分别导入。

## 本版更新

- 地图搜索结果支持长按选词、复制。
- 窗口请求当前分辨率下的最高刷新率，适配 30-185Hz 面板；省电模式下不强制。
- 原生库改为安装时解压，前台服务被容器拦截时任务继续执行。

## 容器注意事项

- 地图黑屏或闪烁：地图右上角筛选 → 兼容渲染 → 打开「纹理模式」，返回首页后重新进入地图。
- 文件选择器看不到 XLSX：先把文件复制到 `Download` 或卓易通共享文件夹，再重新选择。
- 反馈问题：统一管理 → 日志 → 导出诊断，通过系统分享发出。

## 天地图 Key

若使用「Android 平台」Key，需在天地图控制台为 `com.selfuse.cellmap.huawei` + 上述 SHA-1 单独绑定；浏览器端 Key 不受包名限制。两个版本共用同一份 Key 配额。
