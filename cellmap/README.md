# 基站地图 CellMap

自用 Android 基站查询工具。导入 XLSX 台账后，按联通/电信、共享/独享四色分类标注，生成压缩优化数据集，并在 MapLibre 地图上按区域、制式、频段与分类查询。

## 环境要求

- Android Studio Ladybug 或更新版本
- JDK 17
- Android SDK 35，最低运行 Android 7.0（API 24）

## 构建

两个渠道使用不同包名，可同机共存：

```bash
cd cellmap
# 荣耀 / MagicOS 版，包名 com.selfuse.cellmap.honor
./gradlew assembleHonorDebug

# 华为鸿蒙 / 卓易通版，包名 com.selfuse.cellmap.huawei
./gradlew assembleHuaweiDebug
```

产物位于 `app/build/outputs/apk/honor/debug/` 与 `app/build/outputs/apk/huawei/debug/`。

首次构建前在 `cellmap/local.properties` 写入本机 SDK 路径：

```properties
sdk.dir=/path/to/Android/Sdk
```

也可用 `ANDROID_HOME` 环境变量代替。产物位于 `app/build/outputs/apk/debug/`。

## 首次配置

1. 申请天地图 Key：https://console.tianditu.gov.cn/ ，创建「浏览器端」Key。
2. 打开应用，进入「Key 管理」，录入 Key 后执行校验。Key 使用 Android Keystore + AES-GCM 加密保存，只存在本机。
3. 授予通知权限，允许导入、标注、优化任务在后台继续运行。
4. 在系统设置中把应用加入电池优化白名单，避免长任务被中断。

没有可用 Key 时地图显示纯色底图，基站图层与查询仍可正常使用；进入地图时会探测当前 Key，鉴权失败时自动标记失效并切换到下一个可用 Key。

## 华为 Mate 60 Pro 与卓易通

HarmonyOS 6.1 使用纯鸿蒙内核，系统本身不安装 Android APK，需要在卓易通中运行：

1. 将 `dist/huawei/cellmap-huawei-1.9.0.apk` 传到手机，在卓易通内选择「本地安装」并允许安装未知来源应用。
2. 首次启动授予通知权限；若容器内无法跳转电池优化设置，可忽略，导入时保持应用在前台。
3. 地图黑屏或闪烁时，进入地图右上角筛选面板，打开「兼容渲染 → 纹理模式」，返回首页后重新进入地图。
4. 文件选择器看不到 XLSX 时，先在华为文件管理把文件复制到 `Download` 或卓易通的共享文件夹，再重新选择。
5. 反馈问题时进入「统一管理 → 日志 → 导出诊断」，通过系统分享把文件发出来；容器内的应用私有目录无法直接用文件管理器访问。

容器可能禁止前台服务，导入、标注、优化在前台通知不可用时仍会继续执行，但离开应用后有被系统暂停的风险。

## 使用流程

1. **导入数据**：选择 `.xlsx` 文件，确认表头行与字段映射后开始导入。导入在 WorkManager 前台任务中执行，可暂停、取消与重试。
2. **分类标注**：对未分类记录逐条或批量指定四色分类，完成后确认标注结果。
3. **压缩优化**：生成按缩放级别聚类的 GeoJSONL 数据集与索引，原始数据保持不变，可回退。
4. **地图查询**：按搜索或管理区县定位，叠加筛选条件，查看聚合点与基站详情，支持搜索基站 ID、小区 ID、名称以及每张表自带的其它列；每条结果右侧的展开按钮可查看完整基站信息，结果与详情文本都可长按选词复制。详情面板信息区独立滚动并带滚动条，「关闭 / 居中到该点」固定在面板底部。
5. **按表查看**：地图顶部「全部表格」按钮可选择某次导入的 XLSX，右侧「显示全部」恢复全部表格；4G / 5G / 45 三个按钮可切换单制式或同时显示，只查询该表生成的标注。不同表的表头各自独立保存，未映射的列会原样出现在基站详情里并参与搜索。
6. **方位角扇区**：详情页在存在方位角数据时显示「显示方位角扇区」按钮，按标识点经纬度绘制 64° 波束扇区。经纬度完全相同的标识点合并为一个位置，该位置有几个小区就展开几个扇区；经纬度不同的标识点各自独立展开。每个扇区在波束中轴线上显示小区名称，字号随地图缩放平滑调整，名称带白色描边以适配四种分类底色；点击名称直接打开该小区详情。扇区默认关闭，展开后关闭详情不会消失，可同时展开至多 20 个位置；地图顶部显示「清除扇区」按钮，重新进入同一位置详情可单独隐藏该扇区。
7. **临时标识**：在地图上长按 1.5 秒，在弹出的对话框中填写内容即可生成星形临时标识。编号按黄金角生成高对比度颜色，相邻标识颜色差异明显；点击标识可修改内容或删除，最多 50 个。临时标识只保存在内存中，退出应用后清空。
8. **密集点位**：标注点随双指缩放等比放大或缩小，放大时更易点中。放大到 19 级及以上时，屏幕上距离较近的标注合并为一个半透明大圆点并显示数量，点击后弹出带滚动条的列表，按小区名称陈列并可选择具体小区查看详情；缩回 16 级以下时标注回到真实坐标，不再保留像素偏移。

首页会列出未完成的准备项；缺少 Key、数据或标注时，可直接跳转到对应页面。

## 导入格式

仅支持 `.xlsx`（不支持旧版 `.xls`），单文件上限 200MB。读取第一个工作表。

必填列：

| 字段 | 说明 |
| --- | --- |
| 纬度 | -90 到 90 |
| 经度 | -180 到 180 |
| 承建方 | 联通 / 电信，用于四色分类 |
| 基站 ID | 基站标识 |
| 小区 ID | 小区标识 |
| 是否共享 | 已共享 / 未共享，用于圆点与方块区分 |
| 频段/制式 | 4G / 5G，或 1.8G / 2.1G / 900M / 800M / 3.5G / 2.6G 等频段写法 |

可选列包括基站名称、小区名称、运营商、所属区县、小区覆盖类、频段明细、带宽、上行/下行中心频点、多载波标识、基站部署方式、天线挂高、小区方位角、天线增益、PCI、AAU 数量、RRU 数量、45G 共设备等。表头支持常见别名；只有「频段」列时该列会同时用于识别 4G/5G，导入前可手动调整映射。

「天线挂高」「天线总挂高」「小区总挂高」「小区高度」等写法会归入同一字段。当表头只是近似匹配（例如「带宽(MHz)」「小区高度（米）」）时，映射页会按「标识与名称 / 覆盖与天线 / 频率与带宽 / 小区参数与设备」分组列出建议，逐类确认后才会写入，避免静默错配；不确认即视为不导入该列。

从 1.1.0 覆盖安装会执行数据库增量迁移（`MIGRATION_2_3`、`MIGRATION_3_4`），已导入数据与标注结果保留；新增字段对旧记录为空，重新导入同一文件时仍按「基站 ID + 小区 ID」去重。

同一「基站 ID + 小区 ID」重复导入会被忽略。

## 技术要点

- Kotlin + Jetpack Compose + Material 3，MVVM + Repository，Coroutines/Flow
- Room 业务表与空间索引表同事务写入；不依赖 SQLite 可选模块，新增列通过 `MIGRATION_2_3` 增量迁移
- 地图视野查询只取绘制所需的 9 个列（`StationMarkerRow` 投影），不随字段扩充搬运整行文本，避免大结果集时掉帧
- 每张表的未映射列以 `extraJson` 逐行保存，整行文本去重后写入 `searchText` 供地图搜索；表头识别失败时不会再阻断导入
- 标注点使用指数曲线随层级缩放；16 级以下环偏移归零以保证坐标准确，16 级以上按像素环展开；19 级及以上按屏幕距离合并为半透明圆点，点击弹窗选择具体小区
- 方位角扇区与小区名称共用独立 GeoJSON 源，填充、描边与文字图层按 `kind` 区分，默认 `none` 可见性；按标识点经纬度缓存已展开的扇区，同坐标小区合并为一组，最多 20 组，几何与标签锚点在后台线程一次生成，字号使用缩放表达式，关闭详情不影响已展开内容
- 扇区名称标签由地图渲染，开启重叠与忽略避让以避免漏显，点击查询标签图层并复用基站详情面板，不额外持有选中状态
- 临时标识使用独立 GeoJSON 源与星形图标，图标按颜色缓存；颜色由黄金角确定性生成，长按计时器只观察触摸事件，不拦截地图手势
- 密集点位按屏幕像素距离分组，分组与 GeoJSON 序列化在后台线程完成；合并后不再绘制被折叠的小图标，圆点半径、文字与标记尺寸使用缩放表达式，避免手势期间反复更新图层
- 制式筛选支持 4G、5G 与 45 合并查询；45 模式不附加制式条件，地图与搜索同时返回两代小区
- XLSX 使用平台 SAX 直接解析 OOXML，流式按批写入，不构建工作簿对象
- 地图使用 MapLibre，符号图层绘制四色标记，聚合图层分级展示；天地图影像注记叠加路网、POI 与楼栋名称，可在筛选面板关闭以节省流量与电量
- 地图每次进入都从中国大陆全图视野开始，搜索框、筛选和选中基站不跨次恢复
- 每日首次启动后自动执行一次本地维护：校正就绪状态与 Key、修正空间索引、同步标注统计，并预热区县/频段与底图样式
- 地图性能：GeoJSON 在后台线程生成、点位上限随缩放级别调整、手势期间隐藏密集标记、相机位置不进入 Compose 状态、MapView 延迟到首帧后创建
- 首页使用 LazyColumn 按需组合，任务状态由 WorkManager 变更事件推送，替代定时轮询
- 窗口按当前分辨率请求屏幕支持的最高刷新率（30/60/90/120/144/165/185Hz 由面板决定），省电模式下不强制；系统仍可按温度与内容动态降频
- 搜索结果可展开查看完整基站信息，搜索结果与详情文本支持长按选择与复制
- 后台任务使用前台 Worker 与通知，支持进度、取消与失败重试；容器禁止前台服务时自动降级为普通后台任务
- 原生库安装时解压（legacy packaging），兼容卓易通等虚拟容器的 `.so` 加载
- 诊断日志除写入 `Download` 外，可在管理页通过系统分享导出
- 天地图 Key 经 Keystore 加密；瓦片请求直接从设备发出

## 说明

- 已在 JDK 17 + Android SDK 35 下通过 `./gradlew assembleDebug`，调试包位于 `dist/cellmap-debug.apk`。
- 识别逻辑单元测试：`./gradlew testDebugUnitTest`（覆盖 4G/5G 显式词条、频段写法与表头映射）。
- MapLibre 13.7.1 的 arm64-v8a / x86_64 原生库按 16KB 页对齐，可在 Android 15 及以上 16KB 页设备运行。
- 地图依赖使用 MapLibre `android-sdk-opengl`（OpenGL ES），规避部分设备 Vulkan 驱动初始化失败；地图初始化延迟到地图页，失败时显示错误页而不是闪退。
- 空间索引使用普通表 + B-Tree，不依赖 SQLite `rtree`/`fts4` 可选模块；部分 Android 17 系统 SQLite 未编译这些模块，虚拟表会导致建库失败并闪退。
- 启动步骤、未捕获异常和系统退出原因会写入 `Download/cellmap-diagnostics.txt`，也可在管理页分享导出。
- 每日刷新只读取本地数据，不消耗天地图 Key 配额；同一天重复启动只执行一次。
- 项目仅自用，不上架应用商店。
- Key 与天地图瓦片不随应用分发。
- 修改数据后需重新执行标注与压缩优化，地图才会使用新数据集。
